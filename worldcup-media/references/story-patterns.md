# 故事结构

## 球员人物故事

适合单个球员、教练或关键人物。

结构：

1. 开场判断：一句话说明这个人物为什么值得看。
2. 背景线索：成长、位置、球队角色、世界杯前状态。
3. 转折事件：关键比赛、伤病、争议、替补上位、战术变化。
4. 证据层：数据、采访、官方信息、媒体报道。
5. 公众讨论：球迷分歧、社媒热度、舆论误读。
6. 结尾判断：给出克制判断，说明接下来要看什么。

## 单场比赛复盘

适合一场比赛、淘汰赛节点或爆冷。

结构：

1. 比赛结果和关键时间点。
2. 双方赛前处境。
3. 进球、红黄牌、换人、伤病和VAR节点。
4. 战术变化和数据差异。
5. 赛后官方和媒体声音。
6. 对小组形势或淘汰赛路径的影响。

## 球队线索

适合国家队阵容、核心矛盾、战术变化和赛程压力。

结构：

1. 球队主问题：阵容老化、伤病、锋线效率、防线稳定性、核心缺席等。
2. 核心人物和替补方案。
3. 最近比赛表现。
4. 赛程和分组压力。
5. 数据和专家观点。
6. 可验证的后续观察点。

## 争议背景

适合裁判、冲突、言论、伤病争议和舆论反转。

结构：

1. 争议事实边界：先写已确认事实。
2. 各方说法：官方、当事方、媒体、球迷讨论分开呈现。
3. 时间线：按发布时间排列，不按情绪强度排列。
4. 证据强弱：把报道和推测分开。
5. 影响范围：比赛、球队、人物声誉、后续赛程。
6. 暂时结论：明确哪些问题仍未确认。

## 数据对比

适合球员、球队、战术或赛程对比。

结构：

1. 对比问题。
2. 指标选择和样本范围。
3. 关键数据表。
4. 数据解释。
5. 反例和限制。
6. 面向观众的判断。
